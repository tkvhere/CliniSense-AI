# 🏥 CliniSense AI

> **AI-Powered Clinical Intelligence & Patient Assistance Platform**

CliniSense AI is an intelligent healthcare platform that helps patients upload medical reports, extract text using OCR, analyze laboratory results using AI, generate patient-friendly summaries, calculate health scores, identify health risks, and download professional AI-generated medical reports.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/CliniSense-AI.git
```

## Backend

```bash
cd server

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python app.py
```

## Frontend

```bash
cd client

npm install

npm run dev
```
